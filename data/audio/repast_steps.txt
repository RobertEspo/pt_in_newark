Steps I use to run RePAST_v1.0.0 on my Windows 11, which generates and aligns textgrids. I unfortunately don't remember the steps I took to get it all set up.

1. open WSL (ubuntu)
2. activate environment: 'conda activate transcriber'
3. change directory: 'cd /mnt/c/Users/rober/Desktop/RePAST_v1.0.0'
4. run main script: 'python 99_main.py'
